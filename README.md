# סידור עמודות – ניטור יתושים 🦟

כלי פנימי שמסדר את העמודות בקבצי Excel של ריצות ניטור יתושים (Mosquito Run) לפי הסדר הקבוע של דוח הריצה (Report Run).

## שימוש

1. מפעילים את `סידור עמודות.exe` (או `הפעלה.bat` אם Python מותקן).
2. גוררים לחלון קובץ אקסל אחד או יותר, או לוחצים על האזור ובוחרים קבצים.
3. לוחצים **סדר את הקבצים**.

לצד כל קובץ נשמר עותק בשם `<שם הקובץ> - מסודר.xlsx`. הקובץ המקורי לא משתנה.

## איך זה עובד

- סדר 20 העמודות קבוע בקוד (`COLUMN_ORDER` בראש `סידור_עמודות.py`), יחד עם רוחב כל עמודה.
- התוכנה מאתרת את שורת הכותרות בכל גיליון ומתאימה עמודות לפי **שם הכותרת**, כך שסדר העמודות בקובץ המקור לא משנה.
- עמודה שחסרה בקובץ נוספת ריקה במקום הנכון. עמודה שלא קיימת בסדר הקבוע מועברת לסוף.
- עיצוב התאים, רוחב העמודות וקישורים נשמרים.

## קבצים

| קובץ | תיאור |
|---|---|
| `סידור_עמודות.py` | קוד המקור (Python + tkinter) |
| `סידור עמודות.exe` | גרסה ארוזה שרצה בלי התקנת Python |
| `הפעלה.bat` | הפעלה מקוד המקור |
| `mosquito.ico` | אייקון היתוש |
| `טמפלייט להלבנת תוכנה.docx` | הטמפלייט של שיבא להלבנת תוכנה |
| `טופס הלבנה - סידור עמודות.docx` | טופס ההלבנה המלא עבור הכלי |

## הרצה מקוד המקור

```
pip install openpyxl tkinterdnd2
python סידור_עמודות.py
```

`tkinterdnd2` נדרשת רק לגרירת קבצים. בלעדיה בוחרים קבצים בלחיצה.

## בניית ה-exe

```
pip install pyinstaller
pyinstaller --onefile --windowed --name MosquitoSorter --icon mosquito.ico --add-data "mosquito.ico;." --collect-all tkinterdnd2 סידור_עמודות.py
```

אחרי בנייה מחדש טביעת ה-SHA-256 של הקובץ משתנה, וצריך לעדכן אותה בטופס ההלבנה.

## שינוי סדר העמודות

אם הסדר בדוח הריצה משתנה, מעדכנים את הרשימה `COLUMN_ORDER` בראש `סידור_עמודות.py` ובונים מחדש את ה-exe.
