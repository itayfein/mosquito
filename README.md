# MosquiOrder – סידור עמודות לניטור יתושים 🦟

כלי פנימי שמסדר את העמודות בקבצי Excel של ריצות ניטור יתושים (Mosquito Run) לפי הסדר הקבוע של דוח הריצה (Report Run).

## שימוש

1. מפעילים את התוכנה באחת הדרכים:
   - **גרסה ניידת (קובץ אחד), למחשב רגיל:** מעתיקים את `MosquiOrder-<גרסה>-portable.exe` לכל מקום ומפעילים אותו.
   - **גרסת תיקייה, למערכת סגורה או להלבנה:** מחלצים את `MosquiOrder-<גרסה>.zip` ומפעילים את `MosquiOrder.exe` מתוך התיקייה. התיקייה `_internal` חייבת להישאר לידו.
   - **מקוד המקור:** `הפעלה.bat`, אם Python מותקן.
2. גוררים לחלון קובץ אקסל אחד או יותר, או תיקייה שלמה. אפשר גם ללחוץ על האזור או על Ctrl+O ולבחור קבצים.
3. לוחצים **סדר את הקבצים**. העיבוד רץ ברקע והממשק לא נתקע.
4. לחיצה כפולה על שורה ברשימה פותחת את הקובץ המסודר.

לצד כל קובץ נשמר עותק בשם `<שם הקובץ> - מסודר.xlsx`. הקובץ המקורי לא משתנה.

## מה חדש בגרסה 2.0

- **אבטחה:** בנייה כתיקייה ולא כקובץ שנפרס ל-TEMP, בלי רכיבי רשת או OpenSSL, הגנה מקבצים זדוניים (zip bomb / XXE), ומאקרו וקישורים חיצוניים לא עוברים לפלט. הפירוט המלא ב-[SECURITY.md](SECURITY.md).
- **זיהוי כותרות גמיש:** המערכת מתעלמת מרווחים, פיסוק ואותיות גדולות/קטנות, כך ש-`WNV No.` = `wnv no`. אפשר להגדיר שמות חלופיים (aliases).
- **שינוי סדר העמודות בלי בנייה מחדש:** מעתיקים את `columns.example.json` לשם `columns.json` ליד ה-exe ועורכים אותו. ה-hash של ה-exe לא משתנה ולכן לא צריך הלבנה מחדש.
- **שימור מבנה:** איחודי תאים, אימות נתונים (רשימות נפתחות), הערות, עמודות מוסתרות וקישורים עוברים יחד עם העמודה. שורת הכותרת מוקפאת.
- **דיווח:** עמודות חסרות, עמודות נוספות, כותרות כפולות ומה לא הועבר.
- עיבוד ברקע עם פס התקדמות, גרירת תיקייה שלמה ותמיכה ב-xlsm.

## קבצים

| קובץ | תיאור |
|---|---|
| `core.py` | לוגיקת הסידור ובדיקות הקלט (בלי ממשק) |
| `app.py` | ממשק המשתמש (tkinter) |
| `columns.example.json` | דוגמה לקובץ הגדרות סדר עמודות |
| `tests/` | בדיקות אוטומטיות (pytest) |
| `build.ps1`, `mosquiorder.spec`, `version_info.txt` | בנייה (גרסת תיקייה, להלבנה) |
| `mosquiorder-portable.spec` | בנייה של הגרסה הניידת (קובץ יחיד) |
| `SECURITY.md` | דוח בדיקת אבטחה |
| `טופס הלבנה - סידור עמודות.docx` | טופס ההלבנה המעודכן |

## הרצה מקוד המקור

```
pip install -r requirements.txt
python app.py
```

## בנייה

```
pip install -r requirements-build.txt
powershell -ExecutionPolicy Bypass -File build.ps1
```

הסקריפט מריץ בדיקות, bandit ו-pip-audit, בונה את `dist\MosquiOrder\` ומריץ עליו בדיקה עצמית. בסוף הוא מפיק את `dist\MosquiOrder-<גרסה>.zip` (להלבנה), את `dist\MosquiOrder-<גרסה>-portable.exe` (קובץ יחיד למחשבים רגילים, שנפרס ל-TEMP ולכן לא מתאים להלבנה) ואת `dist\SHA256SUMS.txt`. בכל בנייה ה-hash משתנה, וצריך לעדכן אותו בטופס ההלבנה.

## קובץ columns.json

```json
{
  "columns": [
    {"name": "WNV No.", "width": 9.2, "aliases": ["WNV number"]},
    {"name": "מזהה מבחנה", "width": 28.2}
  ],
  "freeze_header": true,
  "min_header_matches": 2
}
```

השדות המותרים הם רק אלה שמופיעים בדוגמה. אם הקובץ לא תקין, התוכנה מציגה אזהרה וממשיכה עם הסדר המובנה.
